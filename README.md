
# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is an online plant shopping application
built with React, Vite, and Redux Toolkit.

## Features

- Landing page with a welcome message and Get Started button
- Plant listings organized into multiple categories
- Plant images, descriptions, and prices
- Add to Cart functionality
- Dynamic shopping cart quantity indicator
- Increase and decrease product quantities
- Remove products from the shopping cart
- Automatic subtotal and total price calculation
- Continue Shopping navigation
- Checkout button displaying a Coming Soon message

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- Vite
- CSS
